# 📺 BrightTV Viewership Analytics

> An end-to-end Business Intelligence project that transforms raw subscriber and viewership data into actionable insights using SQL, Excel, Power BI, Looker Studio, and a live analytics web application.

**Interactive Dashboard:**

## 📌 Business Problem

BrightTV's Customer Value Management (CVM) team required data-driven insights to increase subscriber growth and improve viewer engagement by understanding audience behaviour and content consumption. :contentReference[oaicite:0]{index=0}

## 🚀 Solution

## 💡 Key Insights

- SuperSport Live Channels generated the highest viewership.
- Weekday viewing exceeded weekend consumption.
- Early Adults represented the largest audience segment.
- Viewer engagement increased steadily from January to March. :contentReference[oaicite:1]{index=1}
